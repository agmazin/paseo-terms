# Paseo "Термины"

Плагин Paseo: в русском интерфейсе вместо "рабочее пространство" пишет "папка". Просьба Александра
от 21.10.2026: "для менталитета русского лучше так". Пара к "Папкам" (бывшие "Диалоги",
`projects/local/paseo-dialogs`, 0.7.0): там переименован сам виджет, здесь - родные надписи Paseo.
Один плагин - одна задача, поэтому подмена не вшита в "Папки".

Состояние на 21.10.2026: версия 0.1.0 проверена на тестовом демоне, ждёт приёмки Александра;
в основной Paseo не ставилась. Проверка - `docs/verification-0.1.0.md`.

## Как устроено

- `shared/dictionary.ts` - 60 пар "фраза Paseo" -> "фраза с папкой", окончания подобраны вручную.
  `{{count}}`, `{{target}}`, `{{projectName}}` - подстановки i18next, в замене те же имена.
- `shared/model.ts` - сравнение только всей надписи целиком (пробелы по краям сохраняются),
  шаблоны с подстановками - якорное регулярное выражение по всей строке. Тесты - `tests/model.test.mts`.
- `client/web.ts` - весь DOM, только под `Platform.OS === "web"` (это и Electron, и веб).
  MutationObserver на текстовых узлах и атрибутах `aria-label`, `placeholder`, `title`; замена
  происходит до отрисовки, родное слово не мелькает. Один экземпляр на окно.
- Не трогает: чат (`[data-testid="agent-chat-scroll"]`), contenteditable, `pre`, `code`, терминал
  (`.xterm`), редакторы; текст внутри `textarea`, `input`, `select` (значение поля). У самих полей
  `placeholder` и `aria-label` меняются - так меняется подсказка в ⌘K.
- Поиск ⌘K подсвечивает найденные буквы и режет надпись на куски ("Новое " + "раб" + "очее
  пространство"). Такая надпись собирается целиком (до трёх уровней вверх, до 400 символов),
  перевод пишется в первый кусок, остальные пустеют; подсветка у переведённой строки пропадает.
- Отключение плагина возвращает родные надписи там, где узел ещё показывает нашу замену.
- Ограничение: ⌘K фильтрует по родным словам Paseo - "раб" находит "Новая папка", "пап" не находит.
  Нативные меню macOS и системные окна подтверждения не в DOM и не меняются.

## После обновления Paseo

```sh
npm run extract   # сверка словаря с бандлом /Applications/Paseo.app/.../web/index-*.js
```

Скрипт `scripts/extract.mts` вытаскивает из бандла все строки со словом "пространств"
(в бандле они лежат \uXXXX-экранированием), пишет список в `docs/phrases-<версия>.txt` и печатает
"НОВАЯ" - фразы, которым нужен перевод в словаре, "НЕТ" - фразы, исчезнувшие из Paseo. Новые
фразы дописать в `shared/dictionary.ts`, обновить число в тесте, `npm test`, проверка в браузере.
Пока словарь не обновлён, новые надписи просто остаются родными.
